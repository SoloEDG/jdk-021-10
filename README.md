# 午市厨房

需要 Node.js 22 或更新版本。

```sh
npm install
npm run dev
```

类型检查及生产构建：

```sh
npm run typecheck
npm run build
```

Docker 启动：

```sh
docker compose up --build
```

打开 http://localhost:18221 。

## 主厨教学

主厨教学从一张香煎牛排单开始，带新玩家走完：接单 → 备料 → 合适火候起锅 → 装盘 → 正确上菜。

- **按业务状态判定**：每一步都读取厨房的真实状态与事件（订单、份量、灶台计时、出餐台），点过某个按钮不算完成。被厨房拒绝的操作不会让步骤通过。
- **先做后学**：教学打开时会认领厨房里已经做过的那张牛排单，并用整局的事件记录补判已完成步骤。为别的客人做的牛排不会被误认成教学目标；派生的下游事实（例如已上菜）可以反推上游步骤，但品质不合格的交付不会教会火候。
- **暂停与自由练习**：暂停讲解会冻结练习厨房的计时与操作；自由练习不会来新客、不计入本局收入。
- **重演**：可从任意步骤重新演示。只重置教学自己拥有的场景（教学目标单、教学份量、教学菜品与练习账目），并自动摆好演示所需的半成品；真实营业的收入与历史最佳不受影响。
- **设备占用**：教学只把灶台标为“演示位”，从不拦截正常出餐。演示位被别的订单占用时，会改用空闲设备并说明原因；全部占用时就等待。教学结束、完成或进入自由练习都会立刻释放演示位。
- **导演配置**：面板里的「✎ 教学配置」可以编辑教学 JSON。应用前会校验依赖步骤、失败分支的循环出口和 `onExhausted` 是否向后推进；有问题时逐条列出，不改动当前厨房。内置失败分支示例：牛排烧糊 → 丢弃 → 回到备料重做，重试上限后按 `onExhausted` 退出。

教学数据在 `src/features/tutorial/model/lesson.ts`，步骤判定在 `lib/senses.ts`，流程控制在 `model/director.ts`。练习厨房是真实营业状态的副本，因此教学的任何重置都不会写回这一局。
